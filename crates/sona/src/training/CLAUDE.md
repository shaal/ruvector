# sona/src/training

Templated training pipelines for specialized model adaptation.

## Files

- `mod.rs` — Module entry + crate-level training docs.
- `templates.rs` — Pre-configured training setups for common verticals.
- `factory.rs` — Agent factory (instantiate specialized agents from templates).
- `pipeline.rs` — Structured training workflows.
- `federated.rs` — Distributed training across ephemeral agents.
- `metrics.rs` — Training analytics + result types.
