# ruqu-exotic/tests

Integration and discovery-pipeline tests.

## Files

- `test_exotic.rs` — Smoke + correctness tests per exotic-algorithm module.
- `test_discovery_pipeline.rs` — End-to-end discovery pipeline (algorithms-as-probes).
- `test_discovery_cross.rs` — Cross-module discovery interactions.
- `test_discovery_phase2.rs` — Phase-2 (expanded) discovery experiments.

These tests are research-tier — focus is correctness of the hybrid algorithms rather than performance regressions.
