# ruqu-exotic/src

Eight flat modules — one per exotic algorithm. All re-exported via `lib.rs`.

## Files

- `lib.rs` — Crate doc with module table; declares all eight modules.
- `quantum_decay.rs` — Amplitude-space decoherence as replacement for TTL eviction.
- `interference_search.rs` — Constructive/destructive interference reranking.
- `quantum_collapse.rs` — Probabilistic collapse from superposition for top-k retrieval.
- `reasoning_qec.rs` — Surface-code error correction applied to reasoning traces.
- `swarm_interference.rs` — Agent consensus via quantum interference.
- `syndrome_diagnosis.rs` — System health via QEC-style syndrome extraction.
- `reversible_memory.rs` — Bidirectional state for counterfactual debugging.
- `reality_check.rs` — In-browser verification circuits.
