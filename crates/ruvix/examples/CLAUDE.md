# ruvix/examples

Worked examples demonstrating RuVix end-to-end usage. Each subdirectory is its own Cargo package, member of the `ruvix` workspace.

## Subdirs

- `cognitive_demo/` — `ruvix-demo` package. Comprehensive RVF cognitive pipeline exercising ALL kernel features (5 components,
  3 region types, 3 proof tiers, all 12 syscalls).
- `rvf-demos/swarm-consensus/` — `rvf-swarm-demo` package. Multi-agent coordination on RuVix.
