# ruQu/examples

Runnable examples for `ruqu` — demonstrate coherence-gate workflows and validate the algorithmic claims.

## Files

- `coherence_gate_breakthrough.rs` — Showcases the dynamic-min-cut coherence gate breakthrough.
- `coherence_simulation.rs` — Full coherence-pipeline simulation.
- `early_warning_validation.rs` — Validates early-warning prediction quality.
- `integrated_qec_simulation.rs` — End-to-end QEC integration (likely consuming `fusion-blossom`).
- `mwpm_comparison_benchmark.rs` — Compares against Minimum Weight Perfect Matching baseline.
- `quantum_fabric_basic.rs` — Minimal "hello world" of the 256-tile fabric.
- `validated_coherence_gate.rs` — Gate with rigorous validation harness.

Run via `cargo run --example <name> -p ruqu`.
