# ruQu/src/bin

Standalone binaries for the `ruqu` crate.

## Files

- `ruqu_demo.rs` — Interactive demo of syndrome processing and coherence gating.
- `ruqu_predictive_eval.rs` — Predictive evaluation harness for early-warning validation of the coherence gate.

Run via `cargo run --bin ruqu_demo` or `cargo run --bin ruqu_predictive_eval`.
