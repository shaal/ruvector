# prime-radiant/examples

Runnable demos for the universal coherence engine.

## Files

- `basic_coherence.rs` — minimal substrate + engine + residual/energy compute.
- `compute_ladder.rs` — drives the 4-lane execution ladder (Reflex/Retrieval/Heavy/Human).
- `governance_audit.rs` — policy bundles, witness writing, lineage replay.
- `llm_validation.rs` — using the engine as an LLM hallucination guard.
- `memory_tracking.rs` — tracking memory usage across long runs.

Run via `cargo run --example <name> -p prime-radiant`.
