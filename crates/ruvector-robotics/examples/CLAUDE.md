# ruvector-robotics/examples

Runnable demos for the robotics platform. Each is a single-file `cargo run --example <name>` target.

## Files

- `behavior_tree.rs` — composes a behavior tree and ticks it.
- `cognitive_loop.rs` — end-to-end perceive-think-act-learn loop.
- `obstacle_detection.rs` — synthetic cloud → clusters → bounding boxes.
- `spatial_indexing.rs` — load a cloud into `SpatialIndex` and run kNN queries.
- `swarm_coordination.rs` — multi-robot swarm-intelligence demo.
