# rvf-node/npm

Per-platform prebuilt N-API binaries, one directory per target triple. napi-rs publishes each as its own optional dependency of the main `rvf-node` npm package.

## Subdirs

- `darwin-arm64/` — macOS Apple Silicon `.node` binary + package.json
- `darwin-x64/` — macOS Intel
- `linux-arm64-gnu/` — Linux aarch64 (glibc)
- `linux-x64-gnu/` — Linux x86_64 (glibc)
- `win32-x64-msvc/` — Windows x86_64 (MSVC)

Regenerated by the napi-rs build pipeline; do not edit binaries by hand.
