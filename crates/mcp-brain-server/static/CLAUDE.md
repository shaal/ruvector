# mcp-brain-server/static

Static assets served by the brain HTTP server.

## Files

- `index.html` — landing page.
- `origin.html` — origin / provenance page.
- `agent-guide.md` — agent-facing usage guide (markdown).
- `brain-manifest.json` — machine-readable manifest of brain capabilities/endpoints.
- `og-image.svg` — Open Graph preview image.
- `robots.txt`, `sitemap.xml` — crawler controls.
