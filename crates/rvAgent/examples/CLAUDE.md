# rvAgent/examples

Demo shell scripts that drive the `rvagent` CLI through canonical scenarios.

- `demo_coder_agent.sh` — coder-style agent loop.
- `demo_security_agent.sh` — security-review-style agent loop.
- `demo_tester_agent.sh` — tester-style agent loop.
- `swarm/` — multi-agent topology demos (see its own CLAUDE.md).

These are shell scripts (not Rust examples). Run them after building
`rvagent-cli`.
