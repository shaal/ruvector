# ruvector-nervous-system/benches

Criterion benchmarks.

- `btsp_bench.rs` — Behavioral Time-Series Pattern plasticity throughput.
- `eprop_bench.rs` — e-prop online-learning step latency.
- `ewc_bench.rs` — Elastic Weight Consolidation step (parallelised with `rayon`).
- `hdc_bench.rs` — Hyperdimensional Computing bind / bundle / similarity ops.
- `latency_benchmarks.rs` — end-to-end latency of nervous-system subsystems.
- `pattern_separation.rs` — dentate-gyrus pattern-separation quality vs. speed.
