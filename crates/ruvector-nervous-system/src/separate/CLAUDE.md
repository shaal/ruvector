# ruvector-nervous-system/src/separate

Pattern-separation circuits modelled on the dentate gyrus. Benchmarked in `benches/pattern_separation.rs`.

## Files

- `mod.rs` — façade.
- `dentate.rs` — dentate-gyrus-style separator.
- `projection.rs` — sparse random-projection backbone.
- `sparsification.rs` — output sparsification (k-winner / thresholding).
