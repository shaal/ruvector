# ruvector-nervous-system/src/integration

External-system integration adapters.

## Files

- `mod.rs` — façade.
- `postgres.rs` — PostgreSQL persistence adapter.
- `ruvector.rs` — adapter that bridges the nervous system to `ruvector-core` vector storage.
- `versioning.rs` — versioning of stored state.
- `tests.rs` — module-level integration tests.
