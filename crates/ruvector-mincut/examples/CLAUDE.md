# ruvector-mincut/examples

Runnable examples — `cargo run --example <name>`.

- `localkcut_demo.rs` — local-k-cut discovery demo (deterministic 4-color coding from `src/localkcut`).
- `sparsify_demo.rs` — graph sparsification demo (`src/sparsify`).
- `subpoly_bench.rs` — subpolynomial-algorithm micro-benchmark (`src/subpolynomial`).
