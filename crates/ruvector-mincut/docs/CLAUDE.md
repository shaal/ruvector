# ruvector-mincut/docs

User and engineering documentation for the min-cut library.

## Top-level

- `ALGORITHMS.md` — algorithm catalog (subpolynomial, canonical, local k-cut, etc.).
- `API.md` — public API reference.
- `ARCHITECTURE.md` — internal architecture overview.
- `BENCHMARK_REPORT.md` — measured performance results.
- `PAPER_IMPLEMENTATION.md` — mapping from published paper algorithms to source code.
- `bounded_testing_summary.md` — bounded-instance testing notes.
- `sparsification_implementation.md` — sparsifier implementation notes.
- `witness-quick-reference.md`, `witness-trees.md` — witness chain / proof tree reference.

## Subdirectories

- `adr/` — Architecture Decision Records (Anytime-Valid Coherence Gate, JTree decomposition, BMSSP, SOTA optimization addenda, design criteria, roadmap, applications appendix).
- `guide/` — 8-part numbered user guide.
- `security/` — security review documents (BMSSP).
