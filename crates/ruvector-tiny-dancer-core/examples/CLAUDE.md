# ruvector-tiny-dancer-core/examples

Runnable examples.

- `admin-server.rs` — runs the admin HTTP API (`src/api.rs`).
- `train-model.rs` — knowledge-distillation training loop.
- `metrics_example.rs` — wire up metrics.
- `tracing_example.rs` — wire up tracing.
- `full_observability.rs` — combined metrics + tracing.
- `OBSERVABILITY_EXAMPLES.md` — walkthrough for the above observability examples.
