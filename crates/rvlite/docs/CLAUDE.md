# rvlite/docs

Design / architecture / implementation docs for RvLite. Mostly historical
records of the SPARC-style design process and integration learnings.

## Notable files
- `01_SPECIFICATION.md`, `02_API_SPECIFICATION.md` - top-level spec.
- `03_IMPLEMENTATION_ROADMAP.md` - phased roadmap.
- `00_EXISTING_WASM_ANALYSIS.md` - upstream WASM crate reuse analysis.
- `04_REVISED_ARCHITECTURE_MAX_REUSE.md`,
  `05_ARCHITECTURE_REVIEW_AND_VALIDATION.md` - architecture iterations.
- `CYPHER_IMPLEMENTATION.md`, `SPARQL_IMPLEMENTATION.md`,
  `SQL_IMPLEMENTATION.md` - per-engine implementation notes.
- `GETRANDOM_RESOLUTION_STRATEGY.md`, `GETRANDOM_RESOLUTION_SUCCESS.md` -
  notes on the `getrandom 0.2 / 0.3` WASM compatibility fix.
- `INTEGRATION_SUCCESS.md`, `POC_RESULTS.md` - integration milestones.
- `SPARC_OVERVIEW.md` - overall SPARC methodology overview as applied here.
