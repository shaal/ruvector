# rvlite/examples

Browser-side examples for the RvLite WASM bundle.

## Files
- `demo.html` - minimal standalone HTML demo loading the WASM module.
- `env-polyfill.js` - polyfill to support environments that need it.
- `dashboard/` - full React + Vite + TypeScript dashboard application
  (see `dashboard/CLAUDE.md`).
