# rvlite/examples/dashboard/docs

Integration / feature docs and sample data for the dashboard demo.

## Files
- `IMPLEMENTATION_SUMMARY.md` - high-level implementation overview.
- `INTEGRATION_GUIDE.md` - how to wire the dashboard into a host app.
- `QUICK_REFERENCE.md` - dev quick-reference.
- `VISUAL_INTEGRATION_MAP.md` - diagram of integration touch points.
- `bulk-import-code.tsx` - reference React snippet for the bulk-import
  feature.
- `sample-bulk-import.csv`, `sample-bulk-import.json` - sample datasets
  for testing the bulk-import flow.
