# rvlite/examples/dashboard/src

React + TypeScript dashboard source.

## Files
- `main.tsx` - React entry point.
- `App.tsx` - root app component (`App.tsx.backup` retains prior state).
- `App.css`, `index.css` - styles.
- `FilterBuilder.tsx` - filter-builder UI component used in queries.
- `hero.ts` - hero/landing section helpers.
- `CODE_SNIPPETS.md`, `FILTER_BUILDER_DEMO.md`, `IMPLEMENTATION_GUIDE.md` -
  developer notes / sample snippets.

## Subdirs
- `assets/` - imported static assets (e.g. `react.svg`).
- `components/` - React components (`GraphVisualization`,
  `SimulationEngine`, `SupplyChainSimulation`).
- `hooks/` - React hooks (`useRvLite`, `useLearning`).
- `lib/` - TS libraries (`NeuralEngine`).
