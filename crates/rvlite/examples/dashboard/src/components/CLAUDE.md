# rvlite/examples/dashboard/src/components

React components for the dashboard UI.

## Files
- `GraphVisualization.tsx` - graph rendering (consumes Cypher results from
  `useRvLite`).
- `SimulationEngine.tsx` - core simulation engine driver.
- `SupplyChainSimulation.tsx` - supply-chain scenario built on top of the
  simulation engine, showcasing the vector + graph queries.
