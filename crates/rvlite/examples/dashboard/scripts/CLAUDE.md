# rvlite/examples/dashboard/scripts

Node scripts for debugging the dashboard and running end-to-end smoke
tests against the compiled WASM.

## Files
- `e2e-wasm-test.mjs` - end-to-end WASM smoke test.
- `test-all.mjs` - run the full local test suite.
- `test-sql.mjs` - exercise the SQL engine path.
- `debug-sparql.mjs` - debug SPARQL queries.
- `debug-keys.mjs` - inspect IndexedDB keys / state shape.
