# ruvector-learning-wasm/pkg

wasm-pack output directory, published as the `@ruvector/learning-wasm` npm package. Artifacts are committed so consumers can install without a Rust toolchain.

- `package.json` — npm metadata; `"main"`, `"types"`, and the file list of WASM + JS glue.
- `ruvector_learning_wasm.js` — JS glue generated by wasm-bindgen.
- `ruvector_learning_wasm.d.ts` — TypeScript declarations for the public API.
- `ruvector_learning_wasm_bg.wasm` — built WebAssembly module.
- `ruvector_learning_wasm_bg.wasm.d.ts` — low-level WASM bindings type declarations.

Rebuild with `wasm-pack build --release --target bundler` (or similar) from `..`. See `../CLAUDE.md`.
