# ruvector-attention/src/curvature

Curvature-aware primitives shared by hyperbolic / mixed-curvature attention.

## Files

- `mod.rs` — module entry.
- `tangent_space.rs` — tangent-space projection / parallel transport.
- `component_quantizer.rs` — per-curvature-component quantization helpers.
- `fused_attention.rs` — fused mixed-curvature attention kernel.
