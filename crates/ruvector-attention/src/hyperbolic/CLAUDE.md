# ruvector-attention/src/hyperbolic

Attention in hyperbolic / mixed-curvature spaces — better hierarchy modelling.

## Files

- `mod.rs` — module entry.
- `poincare.rs` — Poincare ball model attention.
- `lorentz_cascade.rs` — Lorentz / hyperboloid cascade attention.
- `hyperbolic_attention.rs` — generic hyperbolic attention driver.
- `mixed_curvature.rs` — product-of-spaces mixed-curvature attention.
