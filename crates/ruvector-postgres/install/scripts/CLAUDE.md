# ruvector-postgres/install/scripts

Per-OS setup scripts that install system prerequisites (PostgreSQL, build toolchain) before invoking the main installer.

## Files

- `setup-debian.sh` — Debian/Ubuntu setup (`apt`).
- `setup-rhel.sh` — RHEL/Fedora setup (`yum`/`dnf`).
- `setup-macos.sh` — macOS setup (`brew`).
