# ruvector-postgres/install

Cross-platform installer for the ruvector PostgreSQL extension.

## Files

- `install.sh` — Main installer.
- `quick-start.sh` — One-shot quick-start (default settings).

## Subdirectories

- `config/` — Configuration templates.
- `scripts/` — Per-OS setup scripts (Debian, macOS, RHEL).
- `tests/` — Installer verification.
