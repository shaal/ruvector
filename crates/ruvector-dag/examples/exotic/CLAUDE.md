# ruvector-dag/examples/exotic

Speculative / advanced DAG scenarios demonstrating the SONA + healing + QuDAG stack on unusual workloads.

- `artificial_instincts.rs` — instinct-like reflex behaviours over a DAG of triggers.
- `coherence_safety.rs` — safety enforcement via the mincut coherence gate.
- `federated_coherence.rs` — coherence aggregation across federated nodes (QuDAG).
- `living_simulation.rs` — long-running adaptive simulation using SONA.
- `synthetic_reflex_organism.rs` — couples reflex DAG, healing, and learning.
- `thought_integrity.rs` — drift / integrity monitoring of an agent's "thought" DAG.
- `timing_synchronization.rs` — temporal-BTSP attention with cross-node timing sync.

Most require `default` (`full`) features. See `../CLAUDE.md` and `../../src/CLAUDE.md`.
