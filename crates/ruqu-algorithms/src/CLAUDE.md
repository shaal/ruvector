# ruqu-algorithms/src

One file per algorithm; all surfaced through `lib.rs`.

## Files

- `lib.rs` — module declarations and top-level re-exports.
- `vqe.rs` — VQE driver + ansatz + `h2_hamiltonian()` helper.
- `grover.rs` — Grover search with direct oracle access.
- `qaoa.rs` — QAOA for MaxCut over a `Graph` type.
- `surface_code.rs` — distance-3 surface code simulation + decoding.
