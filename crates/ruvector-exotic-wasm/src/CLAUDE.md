# ruvector-exotic-wasm/src

Exotic coordination primitives source.

- `lib.rs` — module roots; crate-level docs (NAO, Morphogenetic, Time Crystal).
- `nao.rs` — `NeuralAutonomousOrg`: stake-weighted quadratic voting, quorum
  proposals, oscillatory sync. Members, propose/vote/execute API.
- `morphogenetic.rs` — biologically-inspired network: cellular differentiation via
  morphogen gradients, emergent topology, synaptic pruning.
- `time_crystal.rs` — periodic-state primitive inspired by quantum time crystals.
