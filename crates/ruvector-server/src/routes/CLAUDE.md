# ruvector-server/src/routes

axum HTTP route handlers.

## Files

- `mod.rs` — module decls (`collections`, `health`, `points`).
- `collections.rs` — collection CRUD (create / list / get / delete).
- `points.rs` — point/vector CRUD (insert / batch insert / search / delete).
- `health.rs` — liveness/readiness endpoints.
