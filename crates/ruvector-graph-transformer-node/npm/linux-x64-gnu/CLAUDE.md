# ruvector-graph-transformer-node/npm/linux-x64-gnu

Per-platform npm sub-package for the NAPI prebuilt binary targeting **linux-x64-gnu**.

## Files
- `package.json` - npm metadata for this platform; `os`/`cpu` gate
  installation to matching hosts.
- `ruvector-graph-transformer.linux-x64-gnu.node` - prebuilt NAPI addon (only present
  after CI build).
