# ruvector-graph-transformer-node/npm/linux-arm64-musl

Per-platform npm sub-package for the NAPI prebuilt binary targeting **linux-arm64-musl**.

## Files
- `package.json` - npm metadata for this platform; `os`/`cpu` gate
  installation to matching hosts.
- `ruvector-graph-transformer.linux-arm64-musl.node` - prebuilt NAPI addon (only present
  after CI build).
