# ruvector-graph-transformer-node/npm/win32-x64-msvc

Per-platform npm sub-package for the NAPI prebuilt binary targeting **win32-x64-msvc**.

## Files
- `package.json` - npm metadata for this platform; `os`/`cpu` gate
  installation to matching hosts.
- `ruvector-graph-transformer.win32-x64-msvc.node` - prebuilt NAPI addon (only present
  after CI build).
