# ruvector-graph-transformer-node/npm/darwin-x64

Per-platform npm sub-package for the NAPI prebuilt binary targeting **darwin-x64**.

## Files
- `package.json` - npm metadata for this platform; `os`/`cpu` gate
  installation to matching hosts.
- `ruvector-graph-transformer.darwin-x64.node` - prebuilt NAPI addon (only present
  after CI build).
