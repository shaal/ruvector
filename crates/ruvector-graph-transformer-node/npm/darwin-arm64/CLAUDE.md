# ruvector-graph-transformer-node/npm/darwin-arm64

Per-platform npm sub-package for the NAPI prebuilt binary targeting **darwin-arm64**.

## Files
- `package.json` - npm metadata for this platform; `os`/`cpu` gate
  installation to matching hosts.
- `ruvector-graph-transformer.darwin-arm64.node` - prebuilt NAPI addon (only present
  after CI build).
