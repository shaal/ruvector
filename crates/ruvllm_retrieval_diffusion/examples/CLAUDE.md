# ruvllm_retrieval_diffusion/examples

## Files

- `drum_patterns.rs` — drum-pattern domain demo showing the small-vocab plug-in checklist (`vocab_size`, `head_dim`, mask sentinel). Also doubles as a quick smoke test for both `Retriever::generate_fast` and `Diffuser::diffuse`.

Run via `cargo run --example drum_patterns -p ruvllm_retrieval_diffusion`.
