# ruvector-gnn-node/npm/darwin-x64

Per-platform npm sub-package for the NAPI prebuilt binary targeting **darwin-x64**.

## Files
- `package.json` - npm metadata for this platform; declares `os`/`cpu`
  fields so npm picks it up only on matching hosts.
- `ruvector-gnn.darwin-x64.node` - prebuilt NAPI addon (only present after CI build).
