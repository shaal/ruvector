# ruvector-gnn-node/npm/linux-x64-gnu

Per-platform npm sub-package for the NAPI prebuilt binary targeting **linux-x64-gnu**.

## Files
- `package.json` - npm metadata for this platform; declares `os`/`cpu`
  fields so npm picks it up only on matching hosts.
- `ruvector-gnn.linux-x64-gnu.node` - prebuilt NAPI addon (only present after CI build).
