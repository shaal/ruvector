# ruvector-math/benches

Criterion benchmark suites (each registered as a separate `[[bench]]` in `../Cargo.toml`).

- `optimal_transport.rs` — Sinkhorn / Sliced-Wasserstein / Gromov-Wasserstein.
- `information_geometry.rs` — Fisher, natural gradient, K-FAC.
- `product_manifold.rs` — mixed-curvature operations.
- `spectral.rs` — Chebyshev graph filtering / clustering.
- `tropical.rs` — max-plus matrix and polynomial ops.

See `../CLAUDE.md`.
