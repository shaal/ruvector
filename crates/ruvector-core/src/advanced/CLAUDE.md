# ruvector-core/src/advanced

Research-tier extensions to the core engine. Less stable than `advanced_features/`.

## Files

- `mod.rs` — module wiring.
- `hypergraph.rs` — hypergraph index (vectors with multi-way relations).
- `learned_index.rs` — learned (ML-model-driven) index structures.
- `neural_hash.rs` — neural-network-based locality-sensitive hashing.
- `tda.rs` — Topological Data Analysis primitives (persistent homology, simplicial complexes).
