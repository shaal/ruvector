# ui/ruvocal/src/styles/

Global CSS imported from `src/routes/+layout.svelte` (or `app.html`).

## Files

- `main.css` — global styles + Tailwind `@import`s / layer setup.
- `highlight-js.css` — code-syntax-highlight theme used by `highlight.js` inside `lib/components/CodeBlock.svelte`.

## Conventions

- Prefer Tailwind utility classes in components; only add to `main.css` for genuinely global rules.
