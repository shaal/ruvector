# ui/ruvocal/src/routes/api/mcp/

HTTP API for the MCP (Model Context Protocol) integration.

## Subdirectories

- `health/` — health check for configured MCP servers.
- `servers/` — CRUD for the authenticated user's configured MCP servers.

## Related

- Server logic: `lib/server/mcp/`.
- UI: `lib/components/mcp/`.
- Companion service: `mcp-bridge/`.
