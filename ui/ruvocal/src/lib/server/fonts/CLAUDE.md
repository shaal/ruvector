# ui/ruvocal/src/lib/server/fonts/

Bundled Inter TTF font weights, loaded server-side by **satori** (`satori-html` + `@resvg/resvg-js`) when rendering Open Graph / share thumbnail images (see `src/routes/models/[...model]/thumbnail.png/+server.ts`).

## Files

- `Inter-Thin.ttf`, `Inter-ExtraLight.ttf`, `Inter-Light.ttf`, `Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf`, `Inter-Bold.ttf`, `Inter-ExtraBold.ttf`, `Inter-Black.ttf` — Inter font family weights.
