# ui/ruvocal/src/lib/constants/

Static constants and example data used by both client and server.

## Files

- `mcpExamples.ts` — preset MCP server examples shown in `components/mcp/AddServerForm.svelte`.
- `routerExamples.ts` — example LLM-router policies/configs.
- `rvagentPresets.ts` — preset configurations for the in-browser `rvagent` WASM tools.
- `mime.ts` — MIME-type whitelists / mappings used by upload and document handling.
- `pagination.ts` — default page sizes / pagination limits.
- `publicSepToken.ts` — separator token used in conversation/sharing URL encoding.
