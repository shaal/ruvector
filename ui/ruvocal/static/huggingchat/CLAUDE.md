# ui/ruvocal/static/huggingchat/

Branded static assets for the legacy HuggingChat branding (selected with `PUBLIC_APP_ASSETS=huggingchat`).

## Contents

- `favicon.ico`, `favicon.svg`, `favicon-dark.svg`, `favicon-dev.svg` — favicons.
- `apple-touch-icon.png` and `icon-36x36.png` … `icon-512x512.png` — PWA icons.
- `icon.svg`, `logo.svg`, `fulltext-logo.svg` — vector logo / icon variants.
- `manifest.json` — PWA web app manifest.
- `thumbnail.png`, `assistants-thumbnail.png`, `tools-thumbnail.png` — OG/share thumbnails.
- `castle-example.jpg` — example image used in marketing surfaces.
- `omni-welcome.gif` — welcome animation.
- `routes.chat.json` — sample route/conversation data.
