# ui/ruvocal/static/chatui/

Branded static assets for the default `chatui` / ruvocal branding (selected with `PUBLIC_APP_ASSETS=chatui`, the default — see `svelte.config.js`).

## Contents

- `favicon.ico`, `favicon.svg`, `favicon-dark.svg`, `favicon-dev.svg` — favicons.
- `apple-touch-icon.png` and `icon-36x36.png` … `icon-512x512.png` — PWA icons.
- `icon.svg`, `logo.svg` — vector logo / icon.
- `manifest.json` — PWA web app manifest.
- `omni-welcome.gif`, `omni-welcome.png`, `welcome.svg`, `welcome.js` — welcome-screen assets (generated by `scripts/generate-welcome.mjs`).
