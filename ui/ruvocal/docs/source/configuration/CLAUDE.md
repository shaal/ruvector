# ui/ruvocal/docs/source/configuration/

Configuration topic guides for the ruvocal chat-ui.

## Files

- `overview.md` — overview of configurable surfaces (env vars, models, multimodal).
- `common-issues.md` — troubleshooting checklist.
- `llm-router.md` — intelligent model-router config (see `src/lib/server/router/`).
- `mcp-tools.md` — MCP tool-server configuration (see `src/lib/server/mcp/`).
- `metrics.md` — Prometheus metrics setup (see `src/routes/metrics/`).
- `open-id.md` — OpenID Connect authentication setup.
- `theming.md` — UI theming and branding (see `config/branding.env.example`).
