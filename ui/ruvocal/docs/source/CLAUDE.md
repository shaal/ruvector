# ui/ruvocal/docs/source/

User-facing documentation source for the ruvocal (chat-ui) app, organized for static-site rendering.

## Files

- `_toctree.yml` — table-of-contents ordering for the rendered docs.
- `index.md` — landing page (overview, quickstart, env vars).

## Subdirectories

- `configuration/` — config topic pages (MCP tools, LLM router, OpenID, theming, metrics, common issues, overview).
- `developing/` — developer-oriented docs (architecture).
- `installation/` — installation guides (local, docker, helm).
