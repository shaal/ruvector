# examples/

Narrative example scripts (TypeScript + compiled JS) demonstrating `@ruvector/agentic-synth` usage at three difficulty levels.

Subdirectories:

- `beginner/` — `first-dspy-training`, `simple-data-generation`.
- `intermediate/` — `multi-model-comparison`, `self-learning-system`.
- `advanced/` — `custom-learning-system`, `production-pipeline`.

These are bundled into the published tarball via the `files` field (`examples`) and intended to be run with `node` / `tsx`.
