# src/

TypeScript source for `@ruvector/ruvllm-cli`. Compiled to `../dist/` via `tsc`.

- `index.ts` — main entry; sets up commands for inference, benchmarking, and model management.
- `types.ts` — shared TS types (also contains an emitted `.js` with helper enums/constants).

`.js` and `.d.ts` build artifacts are checked in alongside the sources.
