# ruvector-extensions/examples

Top-level example programs demonstrating `ruvector-extensions` usage (separate from the in-source `src/examples/`).

## Files

- `complete-integration.ts` — end-to-end demo combining embeddings, persistence, exporters, and the UI.
- `graph-export-examples.ts` — focused examples for the graph exporters (GraphML, GEXF, Neo4j, D3, NetworkX).

Each `.ts` file has compiled `.js`, `.d.ts`, and source maps in-tree.
