# ruvector-extensions/tests

Test suite for `ruvector-extensions`. Run via `npm test` (`node --test tests/*.test.js`). TypeScript tests are typically compiled before running.

## Files

- `embeddings.test.ts` — tests for the embedding providers and helpers.
- `exporters.test.ts` — tests for the graph exporters.
- `persistence.test.ts` — tests for the persistence module.
- `temporal.test.js` — tests for the temporal tracking module.
