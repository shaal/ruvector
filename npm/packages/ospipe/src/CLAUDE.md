# src/

TypeScript source for `@ruvector/ospipe`. Compiled to `../dist/` via `tsc`.

- `index.ts` — main SDK entry; ospipe API for Screenpipe pipes (memory, search, ingest).
- `wasm.ts` — WASM-backed implementation; exported via the `./wasm` subpath of the parent package.

`.js` / `.d.ts` build artifacts for both files are also checked into the tree.
