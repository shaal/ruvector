# src/generators/

Domain-specific graph generators. Built and published under the `./generators` subpath export.

- `index.ts` — barrel.
- `entity-relationships.ts` — entity-relationship graphs.
- `knowledge-graph.ts` — Neo4j-style knowledge graphs.
- `social-network.ts` — social-network graphs (users, follows, posts).
- `temporal-events.ts` — time-stamped event sequences and lineages.
