# ruvbot / tests / unit

Fast, isolated unit tests organized to mirror `src/`.

## Subdirectories
- `api/` - HTTP API endpoint tests.
- `core/` - Core / RuvBot class tests.
- `domain/` - Domain entity tests (Agent, Session, Memory, Skill).
- `plugins/` - PluginManager tests.
- `security/` - AIDefenceGuard tests.
- `wasm/` - WASM binding helper tests.
- `workers/` - Background worker pool tests.
