# ruvbot / docs

Design and planning documentation for `ruvbot`.

## Files
- `FEATURE_COMPARISON.md` - Comparison vs. similar self-hosted bots.
- `IMPLEMENTATION_PLAN.yaml` - Machine-readable rollout plan / task
  breakdown.
- `adr/` - Architecture Decision Records (ADR-001 .. ADR-015) covering
  topology, multi-tenancy, persistence, workers, integrations, WASM,
  learning, security, hybrid search, multi-channel, swarm coordination,
  LLM providers, GCP deployment, AIDefence, and chat UI.
