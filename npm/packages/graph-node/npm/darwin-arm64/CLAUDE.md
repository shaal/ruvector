# @ruvector/graph-node-darwin-arm64

Per-platform NAPI sub-package: macOS arm64 binary for `@ruvector/graph-node`.

- `package.json` — declares `os: ["darwin"]`, `cpu: ["arm64"]`, main `graph-node.darwin-arm64.node`.

Binary is produced by the parent's `build:napi` and dropped here at publish time.
