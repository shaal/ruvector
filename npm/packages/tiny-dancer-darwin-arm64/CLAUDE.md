# @ruvector/tiny-dancer-darwin-arm64

Platform-specific native (N-API) binary for `@ruvector/tiny-dancer` — macOS Apple Silicon (darwin-arm64). Tiny Dancer is the RuVector agent-routing engine; this package ships only the precompiled `.node` binary and is pulled in as an optional dependency by the cross-platform `@ruvector/tiny-dancer` loader.

## Files

- `package.json` — `@ruvector/tiny-dancer-darwin-arm64` v0.1.15. `os: ["darwin"]`, `cpu: ["arm64"]`. Main and only published file: `ruvector-tiny-dancer.darwin-arm64.node`.
