# @ruvector/tiny-dancer-linux-x64-gnu

Platform-specific native (N-API) binary for `@ruvector/tiny-dancer` — Linux x64 (glibc). Tiny Dancer is the RuVector agent-routing engine; this package ships only the precompiled `.node` binary and is pulled in as an optional dependency by the cross-platform `@ruvector/tiny-dancer` loader.

## Files

- `package.json` — `@ruvector/tiny-dancer-linux-x64-gnu` v0.1.15. `os: ["linux"]`, `cpu: ["x64"]`, `libc: ["glibc"]`. Main and only published file: `ruvector-tiny-dancer.linux-x64-gnu.node`.
