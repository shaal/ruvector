# @ruvector/ruvllm-linux-arm64-gnu

Per-platform NAPI sub-package: Linux arm64 (glibc) binary for `@ruvector/ruvllm`.

- `package.json` — `os: ["linux"]`, `cpu: ["arm64"]`, libc glibc, main `ruvllm.linux-arm64-gnu.node`.

There is also a near-duplicate top-level package at `npm/packages/ruvllm-linux-arm64-gnu/` (the standalone publishable version).
