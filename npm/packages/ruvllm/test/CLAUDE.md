# test/

Node `--test` suites and a manual benchmark runner for `@ruvector/ruvllm`. Run via `npm test`.

- `basic.test.js` — basic engine/session smoke tests.
- `features.test.js` — feature coverage tests.
- `advanced-features.test.js` — advanced features (LoRA, SONA, contrastive, federated, etc.).
- `benchmark.js` — manual performance benchmark runner (not part of `npm test`).
