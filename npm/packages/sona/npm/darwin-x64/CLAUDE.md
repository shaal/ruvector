# @ruvector/sona-darwin-x64

Native N-API binary for `@ruvector/sona` on Intel Mac.

## Files

- `package.json` — `@ruvector/sona-darwin-x64`. `os: ["darwin"]`, `cpu: ["x64"]`. Main and only published file: `sona.darwin-x64.node`.

The parent `@ruvector/sona` lists this as an `optionalDependency` so npm only installs it on macOS x64.
