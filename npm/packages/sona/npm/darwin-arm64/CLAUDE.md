# @ruvector/sona-darwin-arm64

Native N-API binary for `@ruvector/sona` on macOS Apple Silicon.

## Files

- `package.json` — `@ruvector/sona-darwin-arm64` v0.1.5. `os: ["darwin"]`, `cpu: ["arm64"]`. Main and only published file: `sona.darwin-arm64.node`.

The parent `@ruvector/sona` lists this as an `optionalDependency` so npm only installs it on macOS arm64.
