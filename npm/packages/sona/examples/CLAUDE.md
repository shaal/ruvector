# sona/examples

Runnable JavaScript examples for `@ruvector/sona`.

## Files

- `basic-usage.js` — creates a `SonaEngine` with a hidden dimension, records inference trajectories from random query embeddings.
- `custom-config.js` — uses `SonaEngine.withConfig({...})` to demonstrate the LoRA / EWC++ / ReasoningBank tuning knobs.
- `llm-integration.js` — example wiring SONA into an LLM router for continual learning.
