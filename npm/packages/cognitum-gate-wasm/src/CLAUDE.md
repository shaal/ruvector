# cognitum-gate-wasm / src

TypeScript source for `@cognitum/gate`. Currently a single-file public API
backed by the compiled WASM kernel.

## Files
- `index.ts` - All public types (`Verdict`, `Priority`, `RuntimeHint`,
  `GateEvent`, `TopologyType`, `GateConfig`, `TileTopology`,
  `ReceiptStore`, `TileMemoryConfig`) and the CognitumGate class. Built
  via tsup into `dist/esm/index.js`, `dist/cjs/index.js`,
  `dist/types/index.d.ts`.
- `index.js.map`, `index.d.ts.map` - source maps emitted on build.

The wasm-pack output lives in a sibling `wasm/` directory (generated by
`npm run build:wasm` from `../../../crates/cognitum-gate-kernel`).
