# agentic-synth/training/results

Persisted benchmark and training outputs from running the scripts in `../`.

## Files

- `TRAINING_REPORT.md` — narrative report of the latest training run.
- `baseline.json`, `benchmarks.json`, `metrics.json` — baseline and aggregated metrics.
- `generation-1.json` through `generation-5.json` — per-generation training results.
- `optimized-final.json` — final optimized configuration metrics.
