# agentic-synth/docs

Markdown documentation for the `@ruvector/agentic-synth` package — architecture, usage, performance, deployment, troubleshooting, and various implementation/review reports.

## Key documents

- `API.md`, `ADVANCED_USAGE.md`, `EXAMPLES.md`, `CLI_USAGE.md` — user-facing reference.
- `ARCHITECTURE.md`, `ARCHITECTURE_SUMMARY.md`, `IMPLEMENTATION.md`, `IMPLEMENTATION_PLAN.md` — design docs.
- `BENCHMARKS.md`, `BENCHMARK_SUMMARY.md`, `PERFORMANCE.md`, `PERFORMANCE_REPORT.md`, `OPTIMIZATION_GUIDE.md` — perf data.
- `INTEGRATION.md`, `INTEGRATIONS.md` — integration with ruvector / DSPy / providers.
- `DEPLOYMENT.md`, `TROUBLESHOOTING.md`, `CONTRIBUTING.md`, `SECURITY_REVIEW.md`, `QUALITY_REPORT.md`, `NPM_PUBLISH_CHECKLIST.md`.
- `TEST_ANALYSIS_REPORT.md`, `TEST_SUMMARY.md`, `CODE_QUALITY_SUMMARY.md`, `FIXES_SUMMARY.md`, `FINAL_REVIEW.md`, `MISSION_COMPLETE.md`, `PRODUCTION_READY_SUMMARY.md`, `CLI_FIX_SUMMARY.md`, `DIRECTORY_STRUCTURE.md`, `FILES_CREATED.md`, `GITHUB_ISSUE.md`, `VIDEO_DEMO_SCRIPT.md`, `strict-mode-migration.md`.
- `test-reports/` — generated test report markdown.

These docs are not bundled into the published npm tarball (only README.md and CHANGELOG.md are).
