# agentic-synth/config

Example configuration files for the `@ruvector/agentic-synth` CLI.

## Files

- `synth.config.example.json` — template config that users copy to `synth.config.json`. Defines provider (gemini/openrouter), API key, model, cache strategy, generator defaults, vector DB hooks, etc.

Included in published package via `files: ["config"]` in `package.json`.
