# agentic-synth/tests/integration

Integration tests for `@ruvector/agentic-synth` peer-package adapters. May skip if optional peers are not installed.

## Files

- `ruvector.test.js` — verifies `src/adapters/ruvector.js` against the `ruvector` package.
- `robotics.test.js` — verifies `src/adapters/robotics.js` against `agentic-robotics`.
- `midstreamer.test.js` — verifies `src/adapters/midstreamer.js` against `midstreamer`.
