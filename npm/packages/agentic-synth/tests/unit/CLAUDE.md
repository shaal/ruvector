# agentic-synth/tests/unit

Unit tests for individual modules of `@ruvector/agentic-synth`, mirroring the `src/` layout.

## Subdirectories

- `api/` — tests for `src/api/client.js`.
- `cache/` — tests for `src/cache/context-cache.js`.
- `config/` — tests for `src/config/config.js`.
- `generators/` — tests for `src/generators/data-generator.js`.
- `routing/` — tests for `src/routing/model-router.js`.
