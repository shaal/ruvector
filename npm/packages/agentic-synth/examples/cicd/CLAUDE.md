# agentic-synth/examples/cicd

Examples for generating CI/CD test data and pipeline simulations with `@ruvector/agentic-synth`.

## Files

- `pipeline-testing.ts` — synthetic build/deploy pipeline events.
- `test-data-generator.ts` — generates test fixtures for CI workflows.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
