# agentic-synth/examples/security

Security and threat-simulation synthetic data examples using `@ruvector/agentic-synth`.

## Files

- `penetration-testing.ts` — pentest scenario data.
- `security-audit.ts` — audit log / control evidence generation.
- `threat-simulation.ts` — synthetic threat actor behaviors.
- `vulnerability-testing.ts` — vulnerability dataset generation.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
