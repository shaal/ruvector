# agentic-synth/examples/stocks

Financial market synthetic data examples for `@ruvector/agentic-synth`.

## Files

- `market-data.ts` — OHLCV-style market tick data.
- `portfolio-simulation.ts` — portfolio composition / returns.
- `trading-scenarios.ts` — order / execution scenarios.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
