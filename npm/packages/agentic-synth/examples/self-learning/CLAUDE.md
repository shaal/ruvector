# agentic-synth/examples/self-learning

Examples showing continual / reinforcement-learning data generation patterns with `@ruvector/agentic-synth`.

## Files

- `continual-learning.ts` — streams for continual learning setups.
- `feedback-loop.ts` — closed-loop feedback data flows.
- `reinforcement-learning.ts` — RL trajectories / rewards.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
