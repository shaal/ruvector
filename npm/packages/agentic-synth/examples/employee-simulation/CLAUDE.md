# agentic-synth/examples/employee-simulation

Workforce / HR-related synthetic data examples for `@ruvector/agentic-synth`.

## Files

- `organizational-dynamics.ts` — org chart / team interaction simulations.
- `performance-data.ts` — performance review datasets.
- `workforce-behavior.ts` — employee behavior modeling.
- `workforce-planning.ts` — capacity/staffing planning data.
- `workplace-events.ts` — discrete workplace event streams.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
