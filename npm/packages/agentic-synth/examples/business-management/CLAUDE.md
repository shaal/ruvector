# agentic-synth/examples/business-management

Synthetic data examples for CRM, ERP, HR, finance, and operations scenarios powered by `@ruvector/agentic-synth`.

## Files

- `crm-simulation.ts` — customer relationship management data.
- `erp-data.ts` — enterprise resource planning records.
- `financial-planning.ts` — financial forecast / planning datasets.
- `hr-management.ts` — HR records, hiring, attrition.
- `operations.ts` — operational metrics and workflows.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
