# agentic-synth/examples/agentic-jujutsu

Examples integrating `@ruvector/agentic-synth` with the agentic-jujutsu workflow framework — multi-agent data generation, collaborative workflows, version control, quantum-resistant data patterns, and ReasoningBank learning.

## Files

- `multi-agent-data-generation.ts` — fan-out generation across multiple agents.
- `collaborative-workflows.ts` — agents cooperating on a shared dataset.
- `quantum-resistant-data.ts` — synthetic data for post-quantum cryptography scenarios.
- `reasoning-bank-learning.ts` — feeding generated trajectories into ReasoningBank.
- `version-control-integration.ts` — integrating with jujutsu version control.
- `test-suite.ts` — example test harness.
- `RUN_EXAMPLES.md`, `TESTING_REPORT.md` — usage and test results.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
