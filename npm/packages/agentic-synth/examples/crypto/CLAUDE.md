# agentic-synth/examples/crypto

Cryptocurrency / blockchain synthetic data examples using `@ruvector/agentic-synth`.

## Files

- `blockchain-data.ts` — on-chain transaction synth data.
- `defi-scenarios.ts` — DeFi protocol interaction simulations.
- `exchange-data.ts` — exchange order book / trade data.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
