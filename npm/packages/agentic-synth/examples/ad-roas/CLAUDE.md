# agentic-synth/examples/ad-roas

Synthetic data examples for advertising ROAS (Return on Ad Spend) analytics. Demonstrates generating realistic campaign data, analytics pipelines, and optimization simulations using `@ruvector/agentic-synth`.

## Files

- `campaign-data.ts` — generates ad campaign records (impressions, clicks, spend).
- `analytics-pipeline.ts` — end-to-end pipeline that feeds generated data through analytics.
- `optimization-simulator.ts` — simulates ROAS optimization scenarios on synthetic campaigns.

Each `.ts` file has compiled `.js`, `.d.ts`, and `.map` siblings.
