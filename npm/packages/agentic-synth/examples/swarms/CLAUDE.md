# agentic-synth/examples/swarms

Multi-agent swarm scenario data examples for `@ruvector/agentic-synth`.

## Files

- `agent-coordination.ts` — coordination message logs between agents.
- `agent-lifecycle.ts` — agent spawn/exit lifecycle data.
- `collective-intelligence.ts` — emergent collective behavior datasets.
- `distributed-processing.ts` — distributed work distribution traces.

Each `.ts` file has matching compiled `.js`, `.d.ts`, and source maps.
