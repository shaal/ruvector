# tree/react_memo_cache_sentinel/

The largest extracted cluster, named after React's memo cache sentinel symbol. Most of the React-runtime-adjacent code (and a great deal of incidental code that React-aware bundling pulled in) ended up here.

## Subdirs

- `react_memo_cache_sentinel/` - main bucket; hundreds of files (React internals, BedrockRuntime, Anthropic API helpers, HTTP/EventStream marshallers, env vars, Ghostty/iTerm constants, etc.).
- `additionaldirectoriesforclaudemd/` - smaller bucket related to "additional directories for CLAUDE.md" handling (Managed.js, _claude.js, enabledPlugins.js, projectSettings.js).
