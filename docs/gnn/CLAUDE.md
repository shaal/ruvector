## Docs

- `GRAPH_INTEGRATION_SUMMARY.md` - end-to-end graph integration overview.
- `GRAPH_VALIDATION_CHECKLIST.md` - validation checklist for graph features.
- `gnn-layer-implementation.md` - GNN layer implementation notes.
- `graph-attention-implementation-summary.md` - graph attention implementation.
- `hyperbolic-attention-implementation.md` - hyperbolic-space attention.
- `cli-graph-commands.md`, `cli-graph-implementation-summary.md` - CLI surface and impl.
- `cypher-parser-implementation.md` - Cypher parser implementation.
- `ruvector-gnn-node-bindings.md` - Node.js bindings for GNN.
- `training-utilities-implementation.md` - training utilities.
- `graph-wasm-setup.md` - WASM setup for graph layer.
