# docs/examples/musica/scripts/

Utility shell scripts for the Musica example.

## Files

- `check_wasm.sh` - validates the WASM build of Musica.
- `download_test_audio.sh` - downloads audio fixtures into `../test_audio/`.

## Related

- `../` - the Musica crate.
- `../test_audio/` - target directory for downloaded audio.
