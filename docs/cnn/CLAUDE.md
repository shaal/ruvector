# docs/cnn/

Build artifacts for the ruvector CNN WASM demo (not documentation prose). Hosts a pre-built browser demo.

## Files

- `index.html` - browser demo page.
- `ruvector_cnn_wasm.js` - JS glue for the WASM module.
- `ruvector_cnn_wasm_bg.wasm` - compiled WASM binary.
