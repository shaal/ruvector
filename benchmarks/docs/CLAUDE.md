Documentation for the top-level TS/k6 benchmark suite in `../`.

Files:
- `QUICKSTART.md` - 5-minute setup walkthrough: install k6, run `./setup.sh`, configure `.env`, then `npm run test:quick`. Includes the full scenario catalog and dashboard instructions.
- `LOAD_TEST_SCENARIOS.md` - detailed reference of all available load-test scenarios (baselines, bursts, workload mixes, failover, real-world simulations).

These docs describe how to operate the benchmark runner; they do not document the graph-specific suite (`../graph/docs/`) or the quantization benchmark (`../vector-search/`).
