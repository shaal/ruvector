# demos/attention

Demonstrations of the five attention mechanisms exposed by AgentDB.

## Files
- `all-mechanisms.js` - Showcases Multi-Head, Flash, Linear, Hyperbolic, and MoE attention back-to-back with comparative timing.
- `hyperbolic-deep-dive.js` - Focused exploration of hyperbolic attention and the Poincaré ball model for hierarchical data (taxonomies, org charts, concept hierarchies).

## Run
```
node all-mechanisms.js
node hyperbolic-deep-dive.js
```
