# rvf/dashboard/src/views

Top-level dashboard views (one file per screen). Wired together by `../main.ts`.

## Files

- `SolverDashboard.ts` (~58 KB) - Main solver/runtime dashboard.
- `DysonSphereView.ts` (~52 KB) - Dyson sphere exploration.
- `AtlasExplorer.ts` (~29 KB) - Causal atlas explorer.
- `WitnessView.ts` (~29 KB) - Witness/audit-trail view.
- `DiscoveryView.ts` (~24 KB) - Discovery results browser.
- `DocsView.ts` (~31 KB) - In-app documentation viewer.
- `PlanetDashboard.ts` (~19 KB) - Planet detail dashboard.
- `LifeDashboard.ts` (~19 KB) - Life-candidate dashboard.
- `CoherenceHeatmap.ts` (~15 KB) - Heatmap of coherence scores.
- `StatusDashboard.ts` (~14 KB) - System status / health.
- `DownloadView.ts`, `BoundariesView.ts`, `MemoryView.ts`, `BlindTestView.ts` - Auxiliary views.
