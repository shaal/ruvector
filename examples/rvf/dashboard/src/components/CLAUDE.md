# rvf/dashboard/src/components

Reusable UI components for the RVF dashboard.

## Files

- `Sidebar.ts` - Left-nav sidebar (view switching).
- `TimeScrubber.ts` - Timeline scrubber for time-series replay.
- `DownloadProgress.ts` - Progress UI for large model/data downloads.
- `WitnessLog.ts` - Streaming log of solver/witness events.

## Related

- Used by `../views/` and `../main.ts`.
