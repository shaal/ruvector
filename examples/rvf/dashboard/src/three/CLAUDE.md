# rvf/dashboard/src/three

Three.js scene components for 3D visualization.

## Files

- `AtlasGraph.ts` - Causal atlas as a 3D force-directed graph.
- `CausalFlow.ts` - Animated causal flow visualization.
- `CoherenceSurface.ts` - 3D surface plot of coherence fields.
- `DysonSphere3D.ts` (~14 KB) - Dyson sphere visualization.
- `OrbitPreview.ts` - Orbital path preview.
- `PlanetSystem3D.ts` (~20 KB) - Multi-body planetary system scene.
- `LODController.ts` - Level-of-detail controller.

## Related

- Consumed by views in `../views/` (Atlas, DysonSphere, Planet, Boundaries, Discovery).
- 2D charts: `../charts/`.
