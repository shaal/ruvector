# rvf/dashboard/src/charts

D3-based 2D chart components used inside dashboard views.

## Files

- `LightCurveChart.ts` - Time-series light-curve plot (planet transit / variability).
- `MoleculeMatrix.ts` - Molecule presence matrix.
- `RadarChart.ts` - Multi-axis radar/spider chart.
- `SpectrumChart.ts` - Spectral plot.

## Related

- Consumed by views in `../views/`.
- Three.js scenes: `../three/`.
