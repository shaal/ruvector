# rvf

`rvf-examples` crate (own workspace): a large collection of examples for the RVF (RuVector Format / verified-store + runtime) stack. Covers the full RVF surface: types/wire/manifest/index/quant/crypto/runtime/kernel/launch/ebpf/server, plus end-to-end agentic, security, climate, microlensing, genomics, financial, medical, swarm, and dashboard demos.

## Files

- `Cargo.toml` - Manifest with ~70 `[[example]]` entries; depends on the full `rvf-*` crate suite + `ruqu-*`, `axum`, `ed25519-dalek`, `tokio`.
- `Cargo.lock` - Lockfile.
- `manifest.json` - Sample RVF manifest.
- `security_hardened.rvf` (~1.7 MB) - Sealed sample store generated by `security_hardened.rs`.
- `src/lib.rs` - Tiny helpers shared by examples.
- `examples/` - ~70 `.rs` examples covering every facet.
- `data/` - Real CSV datasets used by demos (confirmed_planets, earthquakes, global temperature).
- `output/` - Sample `.rvf` outputs of running each example.
- `scripts/` - Cross-platform launch scripts (`.sh`/`.ps1`) for browser/docker/MCP/Claude appliance demos.
- `dashboard/` - Vite+TypeScript+Three.js dashboard consuming `@ruvector/rvf-solver` WASM.

## How to run

```bash
cargo run -p rvf-examples --example basic_store
cargo run -p rvf-examples --example causal_atlas_dashboard
cargo run -p rvf-examples --example security_hardened --release
cd dashboard && npm install && npm run dev
```

## Tech stack

- Rust 2021 + tokio, axum (HTTP + WS), ed25519-dalek (signing), serde, tempfile.
- Internal: full RVF crate stack and `ruqu-*` (quantum solver).
- Dashboard: TypeScript, Vite, Three.js, D3.
