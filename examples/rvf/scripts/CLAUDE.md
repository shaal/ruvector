# rvf/scripts

Cross-platform launcher scripts for common RVF demos.

## Files

- `rvf-quickstart.sh` / `rvf-quickstart.ps1` - First-run smoke test (build + small example).
- `rvf-docker.sh` - Docker-based launch.
- `rvf-claude-appliance.sh` / `rvf-claude-appliance.ps1` - Boot the Claude Code RVF appliance.
- `rvf-mcp-server.sh` / `rvf-mcp-server.ps1` - Launch the RVF MCP server.
- `rvf-node-example.mjs` - Node.js consumer example.
- `rvf-browser.html` - In-browser RVF demo.

## How to run

```bash
bash /home/user/ruvector/examples/rvf/scripts/rvf-quickstart.sh
bash /home/user/ruvector/examples/rvf/scripts/rvf-claude-appliance.sh
node /home/user/ruvector/examples/rvf/scripts/rvf-node-example.mjs
```
