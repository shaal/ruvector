# dna/ddd

Domain-Driven Design documents for rvDNA. Describes the bounded contexts, aggregates, and high-level architecture.

## Important files
- `domain-model.md` — entities, value objects, aggregates.
- `bounded-context-map.md` — context map showing relationships between contexts (variant calling, biomarkers, pharmacogenomics, etc.).
- `architecture.md` — overall architecture and layering.
