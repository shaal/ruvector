- `ADR-002-quantum-genomics-engine.md` — quantum-inspired genomics engine.
- `ADR-003-genomic-vector-index.md` — HNSW vector index design.
- `ADR-004-genomic-attention-architecture.md` — attention-based sequence analysis.
- `ADR-005-graph-neural-protein-engine.md` — GNN for protein/interaction networks.
- `ADR-006-temporal-epigenomic-engine.md` — epigenomic time series.
- `ADR-007-distributed-genomics-consensus.md` — distributed consensus.
- `ADR-008-wasm-edge-genomics.md` — WASM/edge deployment.
- `ADR-009-variant-calling-pipeline.md` — variant calling.
- `ADR-010-quantum-pharmacogenomics.md` — pharmacogenomics with quantum primitives.
- `ADR-011-performance-targets-and-benchmarks.md` — perf targets.
- `ADR-012-genomic-security-and-privacy.md` — privacy posture.
- `ADR-013-rvdna-ai-native-format.md` — native file format spec.
- `ADR-014-health-biomarker-analysis.md` — biomarker scoring.
- `ADR-015-npm-wasm-biomarker-engine.md` — npm WASM biomarker engine.
