# earthquake-boundary-discovery/src

Single-file source for the earthquake boundary-discovery demo.

## Files

- `main.rs` - Synthesizes/loads earthquake events, builds a similarity graph, runs exact min-cut and spectral coherence to extract boundaries, prints results.
