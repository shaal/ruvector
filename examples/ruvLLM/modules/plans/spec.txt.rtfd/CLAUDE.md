# ruvLLM / modules / plans / spec.txt.rtfd

macOS RTFD (Rich Text Format Directory) bundle containing the master ruvLLM specification.

## Important files
- `TXT.rtf` - the actual RTF spec body (open in TextEdit / `textutil -convert html TXT.rtf` for readable form).
- `favicons.png` - logo embedded in the RTF.
- `1__#$!@%!#__favicons.png`, `2__...`, `3__...`, `4__...` - duplicate image attachments referenced by the RTF (macOS RTFD naming convention).
