# ruvLLM / esp32-flash / npm / web-flasher

Browser-based ESP Web Tools flasher shipped inside the `ruvllm-esp32` npm package.

## Important files
- `index.html` - self-contained HTML page that uses Web Serial / ESP Web Tools to flash firmware from the browser. Distributed by the CLI (`../bin/cli.js`) so users can `ruvllm-esp32 web` and open it locally.
