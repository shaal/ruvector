# ruvLLM / esp32-flash / npm / scripts

OS-specific helper scripts shipped inside the `ruvllm-esp32` npm package.

## Subdirectories
- `windows/` - PowerShell scripts (setup, env, build, flash, monitor) used by `../bin/cli.js` on Windows.

## Related
- CLI driver: `../bin/cli.js`. Equivalent top-level scripts (used outside the npm package): `../../scripts/`.
