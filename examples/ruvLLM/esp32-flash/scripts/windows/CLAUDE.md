# ruvLLM / esp32-flash / scripts / windows

Top-level PowerShell helpers (parallel to the npm-packaged set in `../../npm/scripts/windows/`).

## Important files
- `setup.ps1` - install ESP-IDF / prerequisites.
- `env.ps1` - source ESP-IDF env vars.
- `build.ps1` - build the firmware.
- `flash.ps1` - flash a connected board.
- `monitor.ps1` - open the serial monitor.

## Related
- npm-packaged equivalents (shipped to end users): `../../npm/scripts/windows/`.
