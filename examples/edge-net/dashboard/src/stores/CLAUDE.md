# dashboard/src/stores

Zustand state slices, one per domain.

## Important files
- `cdnStore.ts` — CDN/model distribution state.
- `identityStore.ts` — identity / key state.
- `mcpStore.ts` — MCP tool registry state.
- `networkStore.ts` — peers, stats, topology.
- `wasmStore.ts` — loaded WASM modules state.
