# components/dashboard

Top-level dashboard chrome and panels.

## Important files
- `Header.tsx` — top bar.
- `Sidebar.tsx` — left navigation.
- `ActivityPanel.tsx` — recent activity stream.
- `ConsolePanel.tsx` — log/console view.
- `CreditsPanel.tsx` — credit balance + recent ledger entries.
- `SettingsPanel.tsx` — user / node settings.
