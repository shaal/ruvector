# edge-net/dashboard/src/components

React components for the dashboard, grouped by domain. Each subdirectory roughly maps to a sidebar section.

## Subdirectories
- `brain/` — neural brain status.
- `cdn/` — CDN panel.
- `common/` — shared widgets (StatCard, GlowingBadge, CrystalLoader, ConsentWidget).
- `dashboard/` — chrome (Header, Sidebar, ActivityPanel, ConsolePanel, CreditsPanel, SettingsPanel).
- `docs/` — embedded documentation panel.
- `economics/` — economics overview.
- `identity/` — identity panel.
- `mcp/` — MCP tools surface.
- `network/` — network stats and visualizations.
- `rewards/` — rewards guide.
- `wasm/` — loaded WASM modules.

## Related
- State for each domain lives in `../stores/`.
