# edge-net/pkg/node

Node.js (CommonJS) target build of the edge-net WASM module. Used by server-side / CLI flows; the browser target sits one level up.

## Important files
- `ruvector_edge_net.cjs` + `ruvector_edge_net.d.ts` — Node bindings.
- `ruvector_edge_net_bg.wasm` + `ruvector_edge_net_bg.wasm.d.ts` — compiled WASM artifact.
