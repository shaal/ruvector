# edge-net/docs

Design, architecture, validation, and security documentation for edge-net.

## Important files
- `QDAG_ARCHITECTURE.md` — QDAG credit-ledger architecture.
- `security-architecture.md` + `SECURITY_AUDIT_REPORT.md` + `SECURITY_QUICK_REFERENCE.md` — security posture & audit findings.
- `CONTRIBUTOR_FLOW_VALIDATION_REPORT.md`, `TEST_RESULTS_QDAG_PERSISTENCE.md`, `VALIDATION_SUMMARY.md` — validation results.

## Subdirectories
- `architecture/` — high-level architecture documents.
- `benchmarks/` — benchmark methodology and results.
- `performance/` — performance analyses & optimizations.
- `rac/` — RAC (Reputation/Axiom/Coherence) validation.
- `reports/` — final reports.
- `research/` — exploratory research (economic edge cases, exotic AI features).
