# sevensense-api/src/graphql

GraphQL surface for the 7sense API.

## Files
- `mod.rs` - GraphQL module wiring (router integration).
- `schema.rs` - Root `Query`/`Mutation`/`Subscription` definitions.
- `types.rs` - GraphQL types mirroring the domain entities.
