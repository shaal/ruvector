# exo-manifold/src

## Files

- `lib.rs` — public re-exports.
- `network.rs` — SIREN network implementation (sinusoidal activations).
- `deformation.rs` — smooth manifold deformation operators.
- `retrieval.rs` — continuous nearest-point retrieval.
- `forgetting.rs` — manifold-level forgetting / decay.
- `simd_ops.rs` — SIMD-accelerated kernels.
- `transfer_store.rs` — store for cross-domain manifold transfer.
