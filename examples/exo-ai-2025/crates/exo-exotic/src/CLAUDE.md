# exo-exotic/src

One module per "exotic" cognitive experiment.

## Files

- `lib.rs` — re-exports each experiment module.
- `strange_loops.rs` — self-referential / Hofstadter-style loops.
- `dreams.rs` — offline replay / dream-cycle consolidation.
- `free_energy.rs` — Friston-style free energy minimization.
- `morphogenesis.rs` — pattern-forming dynamics.
- `collective.rs` — collective / multi-agent consciousness.
- `temporal_qualia.rs` — temporal experience encoding.
- `multiple_selves.rs` — concurrent self representations.
- `thermodynamics.rs` — cognitive Landauer accounting.
- `emergence.rs` — emergence-detection scaffolding.
- `black_holes.rs` — "cognitive black hole" attractors.
- `domain_transfer.rs` — cross-domain state movement.

## Subdirectory

- `experiments/` — additional small experiments
  (`causal_emergence`, `memory_mapped_fields`, `neuromorphic_spiking`,
  `quantum_superposition`, `sparse_homology`, `time_crystal_cognition`)
  paralleling the standalone `../../../research/` prototypes.
