# wasm

Umbrella directory for WASM-platform examples in the RuVector monorepo. Currently hosts the iOS/browser optimized WASM vector database example.

## Subdirs

- `ios/` - `ruvector-ios-wasm`: iOS + browser optimized vector DB (HNSW, quantization, SIMD, RL/Q-learning, attention) with Swift bindings.

## Related

- Other WASM examples elsewhere: `examples/onnx-embeddings-wasm`, `examples/prime-radiant/wasm`, `examples/scipix/src/wasm`, `examples/rvf/examples/browser_wasm.rs`.
