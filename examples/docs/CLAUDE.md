# examples/docs

Standalone documentation pages for end-user-facing RuVector features.
Not tied to any single example crate — these are reference docs that
can ship with the examples directory.

## Files

- `graph-cli-usage.md` (~11 KB) — practical usage guide for the
  RuVector graph database CLI: creating graphs, ingestion, queries,
  benchmarks.
- `graph_wasm_usage.html` (~13 KB) — self-contained HTML reference for
  the graph WASM module (open directly in a browser).

## How to view

- Markdown: any renderer (`gh`, `glow`, GitHub web view).
- HTML: open `graph_wasm_usage.html` in any browser.
