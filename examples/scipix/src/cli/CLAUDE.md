# scipix/src/cli

CLI surface for scipix (consumed by `../bin/cli.rs`).

## Files

- `mod.rs` - Top-level CLI parser (clap-derive).
- `output.rs` - Output formatting / colored printing helpers.
- `commands/` - One file per subcommand.

## Related

- Bin: `../bin/cli.rs`.
- Subcommands: `./commands/`.
