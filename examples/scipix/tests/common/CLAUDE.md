# scipix/tests/common

Shared utilities used by the unit and integration test suites.

## Files

- `mod.rs` - Module surface.
- `images.rs` - Generate / load test images.
- `latex.rs` - LaTeX comparison helpers.
- `metrics.rs` - Accuracy / similarity metrics.
- `server.rs` - Start an in-process API server for HTTP tests.
- `types.rs` - Shared test-only types.
