# scipix/assets/fonts

Bundled fonts used by scipix output/rendering pipelines.

## Files

- `DejaVuSans.ttf` (~289 KB) - Wide-coverage Unicode sans font used for math/text rendering when the system font is unavailable.
- `.gitkeep` - Keeps the directory in git when empty.
