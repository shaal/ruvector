# edge / pkg

`wasm-pack` output for `ruvector-edge`, plus standalone browser demos that consume it. Generated by `../scripts/build-wasm.sh`; the demo HTML/TS files are hand-written.

## Important files
- `ruvector_edge.js`, `ruvector_edge.d.ts`, `ruvector_edge_bg.wasm`, `ruvector_edge_bg.wasm.d.ts` - generated WASM bindings.
- `package.json`, `LICENSE` - npm package metadata for the generated module.
- `generator.html` - browser demo that uses the WASM module as a generator.
- `plaid-demo.html`, `plaid-local-learner.ts` - PLAID local-learner browser demo (typescript driver + HTML host).
- `zk-demo.html`, `zk-financial-proofs.ts` - zero-knowledge financial-proof demo.
- `worker.js`, `worker-pool.js` - Web Worker pool used by the demos to keep heavy crypto off the main thread.

## Build
- `bash ../scripts/build-wasm.sh` regenerates the `*.wasm` + `.js` / `.d.ts` files.
- Serve this dir over HTTP (e.g. `python3 -m http.server`) and open `plaid-demo.html` / `zk-demo.html` / `generator.html`.

## Related
- Rust WASM surface: `../src/wasm.rs`, `../src/plaid/wasm.rs`, `../src/plaid/zk_wasm.rs`, `../src/plaid/zk_wasm_prod.rs`.
