# neural-trader/specialized

Specialized non-equities trading flows.

## Files
- `news-trading.js` - Real-time news sentiment, event-driven strategies, earnings reactions, breaking-news detection.
- `prediction-markets.js` - Polymarket integration, EV calculations, market-making, cross-platform arbitrage.
- `sports-betting.js` - Sportsbook arbitrage detection, Kelly position sizing, EV calcs, odds comparison.

## Run
```
npm run specialized:news
npm run specialized:prediction
npm run specialized:sports
```
