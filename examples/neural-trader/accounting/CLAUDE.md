# neural-trader/accounting

Crypto accounting demos that use `@neural-trader/agentic-accounting-rust-core` for tax-grade ledger calculations.

## Files
- `crypto-tax.js` - FIFO/LIFO/HIFO cost-basis, capital gains, tax lot optimization, multi-exchange reconciliation.

## Run
```
npm run accounting:crypto-tax     # from neural-trader/
```
