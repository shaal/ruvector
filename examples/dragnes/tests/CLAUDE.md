# dragnes / tests

Vitest tests for the DrAgnes module.

## Important files
- `classifier.test.ts` - tests for `$lib/dragnes/classifier.ts` (WASM load, inference, Grad-CAM fallback).
- `benchmark.test.ts` - tests for `$lib/dragnes/benchmark.ts`.

## Run
- `npm test` (from `../`) runs `vitest run`.

## Related
